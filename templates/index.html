About This Project

Smart Transit Hyderabad is an ML-powered crowd forecasting system for TSRTC bus routes.


Model: Random Forest Classifier (300 estimators, max depth 18)

Dataset: 10,000 synthetic records with realistic Hyderabad peak patterns

Training features: Hour, Day, Weekend flag, Route, Stop, Weather, Buses Available, Month, Festival flag


Unique features:

  • Hyderabad event calendar (Bonalu, Dussehra, Ganesh Chaturthi, IPL, etc.)
  • Alternate stop suggestions when crowd is predicted High
  • 6-hour ahead forecast on same route & stop
  • Model confidence via predict_proba() with class breakdown
  • Best travel time finder across all 24 hours
  • Auto-fill current time with "Now" button
  • Buses Available as live input (fixed hardcode from v1)
